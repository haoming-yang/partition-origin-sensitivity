# Results

`paper_core_summary.csv` is a frozen paper-facing aggregate copied from the manuscript project. It is not a replacement for per-origin predictions or complete run artifacts.

Generated outputs belong below `outputs/` and are ignored by Git. Each generated run should contain `config.json`, `PROVENANCE.json`, `per_origin_mse.csv`, `per_origin_predictions.npz`, `summary.json`, and training and validation logs.
