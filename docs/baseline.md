# Repository baseline

This repository is assembled as a clean, source-conservative release from the
local experiment archive and isolated Time-Series-Library/model snapshots. The
original manuscript project, source archive, and reference library were not
modified by this assembly.

The first Git commit on `main` is the release baseline. Reproducibility changes
after that point should preserve the distinction between source-backed runs,
reconstructed controls, artifact-dependent workflows, and frozen-artifact-only
evidence described in `docs/experiment_execution_matrix.md`.
